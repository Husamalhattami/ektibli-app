# تطبيق «اكتب لي» (Ektibli App) 🧏‍♂️💬

تطبيق أندرويد متكامل وموجّه لمساعدة الأشخاص الصم وضعاف السمع، يحوّل الكلام والرسائل الصوتية في واتساب إلى **نص كبير فوري وواضح**، مع تنبيهات بصرية واهتزازية فقط ودون أي اعتماد على الصوت أو السماعات.

---

## ✨ المميزات الرئيسية (Core Features)

1. **الاستماع الفوري المباشر (Live Speech-to-Text):**
   - تحويل فوري لكلام المتحدث أمام الهاتف إلى نص مكتوب على الشاشة في الوقت الفعلي.
   - مؤشر بصري لموجات الصوت (Sound Wave Visualizer) للتنبيه بوجود صوت وكلام.
   - إمكانية تسمية المتحدث وتعديل اسمه (مثل: الطبيب، الكاشير، الموظف).
   - أزرار سريعة لمسح النص، نسخه، مشاركته، أو حفظه في السجل.

2. **تحويل صوتيات واتساب إلى نص (WhatsApp Voice Note Transcription):**
   - استقبال الرسائل الصوتية مباشرة عبر ميزة المشاركة في واتساب: **مشاركة ← تطبيق اكتب لي**.
   - دعم كامل لصيغ الصوت: `OPUS`، `OGG`، `MP3`، `M4A`، `WAV`، `AAC`، `3GP`، `AMR`.
   - تفريغ دقيق باللهجات العربية المختلفة عبر Gemini 2.5 Flash بنظام Multimodal Audio.
   - حفظ الملف الصوتي محلياً فور الاستلام لضمان استمرارية أذونات القراءة.

3. **الزر والمساعد العائم فوق واتساب (Floating Overlay Widget):**
   - أيقونة عائمة قابلة للسحب تظهر فوق تطبيق واتساب وجميع التطبيقات الأخرى.
   - عند النقر عليها، تنبثق نافذة مساعدة عائمة للتفريغ الصوتي الفوري أو عرض بطاقة الطوارئ دون مغادرة المحادثة في واتساب.
   - خدمة رصد إشعارات واتساب لاهتزاز الهاتف وتنبيه المستخدم بصرياً فور وصول أي رسالة صوتية.

4. **وضع المحادثة الثنائية (Two-Way Conversation):**
   - واجهة مقسمة للحوار وجهاً لوجه:
     - الطرف المتحدث: كلامه يُفرّغ فوراً مع زر لقلب الشاشة (180°) ليقرأ كلامه من الجهة المقابلة.
     - المستخدم الأصم: خانة كتابة سريعة مع أزرار ردود جاهزة («نعم»، «لا»، «شكراً»، «كم الحساب؟»، «لحظة واحدة»، «أين أوقع؟»).
     - زر **«تكبير الرد»** لعرض النص بحجم عملاق يملأ الشاشة مع خيار القلب 180° للقراءة من مسافة بعيدة.

5. **بطاقة التواصل السريع («أنا لا أسمع، من فضلك اكتب لي»):**
   - بطاقة بصرية عاجلة قابلة للقلب 180° تحتوي على خانة مباشرة تتيح للشخص المقابل كتابة رده مباشرة.

6. **تنبيهات بصرية واهتزازية فقط:**
   - وميض بصري ناعم للشاشة (Screen Flash) عند رصد الكلام أو وصول رسالة.
   - اهتزاز الهاتف (Haptic Feedback) عند بدء الكلام، توقفه، أو اكتمال التفريغ.

7. **تخصيص كامل للمظهر والخط:**
   - شريط تحكم بحجم الخط (من عادي 24sp إلى عملاق 54sp) مع خيار الخط العريض (Bold).
   - 5 أنماط ألوان عالية التباين (أصفر على أسود الفائق، أسود OLED، أبيض ناصع، أزرق نيلي، وأخضر زمردي).
   - سجل محلي كامل (Room Database) لحفظ المحادثات والرسائل المفرغة مع إمكانية البحث والمسح.

## 🛠 التقنيات المستخدمة (Tech Stack)

- **اللغة:** Kotlin 2.2.10
- **واجهة المستخدم:** Jetpack Compose + Material Design 3 (Edge-to-Edge)
- **قاعدة البيانات:** Room Database 2.7.0 مع Kotlin KSP
- **التعرف على الصوت المباشر:** Android `SpeechRecognizer` + `RecognitionListener` (Continuous Mode)
- **تفريغ ملفات الصوت:** Google Gemini 2.5 Flash API (OkHttp Multimodal Audio)
- **الخدمات العائمة:** Android `WindowManager` (`TYPE_APPLICATION_OVERLAY`)
- **رصد الإشعارات:** Android `NotificationListenerService`
- **التنبيهات اللمسية:** Android `Vibrator` / `VibratorManager` (`VibrationEffect`)

## 🔑 إعداد مفتاح الذكاء الاصطناعي (Gemini API Key)

التطبيق مصمم ليعمل بأعلى معايير الأمان دون وضع أي مفاتيح سرية في الكود المصدري أو مستودع GitHub:

### الطريقة الأولى: من داخل التطبيق (الأسهل للمستخدم النهائي)
1. افتح شاشة **«المظهر والخط» (الإعدادات)** داخل التطبيق.
2. انزل إلى خانة **«مفتاح الذكاء الاصطناعي (Gemini API)»**.
3. الصق مفتاحك المجاني (يمكن الحصول عليه مجاناً من [Google AI Studio](https://aistudio.google.com/)).
4. اضغط على **«حفظ المفتاح»**.

### الطريقة الثانية: عبر متغيرات البيئة أثناء البناء
أثناء بناء المشروع، يمكنك تمرير المفتاح في ملف `.env` (الذي يتم تجاهله تلقائياً في `.gitignore`):
```properties
GEMINI_API_KEY=AIzaSyYourSecretKeyHere
```
يقوم Secrets Gradle Plugin بتمريره إلى `BuildConfig.GEMINI_API_KEY` دون كشفه في الكود أو GitHub.

## 🚀 طريقة بناء وتشغيل المشروع (Build & Run)

المشروع يحتوي على ملفات `gradlew` الكاملة:

### 1. استنساخ المستودع:
```bash
git clone https://github.com/your-username/ektibli-app.git
cd ektibli-app
```

### 2. بناء نسخة التجربة (Debug APK):
```bash
./gradlew assembleDebug
```
الملف الناتج: `app/build/outputs/apk/debug/app-debug.apk`

### 3. بناء نسخة الإصدار الموقعة (Release APK):
```bash
STORE_PASSWORD="your_keystore_password" KEY_PASSWORD="your_key_password" ./gradlew assembleRelease
```
الملف الناتج: `app/build/outputs/apk/release/app-release.apk`

### 4. بناء حزمة النشر على Google Play (Release AAB):
```bash
STORE_PASSWORD="your_keystore_password" KEY_PASSWORD="your_key_password" ./gradlew bundleRelease
```
الملف الناتج: `app/build/outputs/bundle/release/app-release.aab`

## 🔒 معلومات التوقيع والـ Keystore

لضمان أمان التطبيق عند النشر:

## 📱 التوافق والأذونات (Compatibility & Permissions)

- **الحد الأدنى للنظام:** Android 7.0 (API 24 Nougat)
- **الإصدار المستهدف:** Android 16 (API 36)
- **الأذونات المطلوبة:**
  - `RECORD_AUDIO`: لاستقبال الصوت المباشر من الميكروفون.
  - `VIBRATE`: لتشغيل التنبيهات الاهتزازية.
  - `INTERNET`: للاتصال بـ Gemini API لتفريغ الصوتيات.
  - `SYSTEM_ALERT_WINDOW`: لتشغيل الزر العائم فوق تطبيق واتساب.
  - `BIND_NOTIFICATION_LISTENER_SERVICE`: لرصد وصول رسائل صوتية جديدة في واتساب.
